# TwoSpace v0.1.0 — Web preview

The first tagged TwoSpace release brings the shared web app together: a journal, four two-person games, daily Spotify picks, activities, and plans across time zones.

**[Open TwoSpace](https://twospace.online)** · **[Setup guide](../../README.md#run-locally)**

## Included

- **Journal:** entries grouped by date, photos, voice messages, replies, hearts, pins, collections, scheduled letters, and photo pairs.
- **Games:** Four-in-a-row, tic-tac-toe, rock/paper/scissors, and Three clues, with shared state, legal-move checks, hidden choices, and rematches.
- **Activities:** separate answers revealed together, drawing turns, and saved date ideas.
- **Music:** one daily Spotify pick per person, a note, official embeds, and past picks.
- **Plans:** call and date proposals, optional visits, both partners’ local times, free hours, and shared checklists.
- **Accounts:** email and Google sign-in, verification and reset emails, profile pictures, and partner invitations.

Shared features unlock when a partner joins. If both people accidentally make their own spaces, an explicit code-based switch moves the member and their profile picture from an otherwise empty space. Invalid invitations leave membership unchanged. For a nonempty space, export any content you want to keep, then leave from Settings before joining another.

## Changes completed for this release

Activities opens on playable games, and the journal uses a chronological feed instead of a dashboard layout. Starting or continuing a game brings its board into view. Saving a journal entry returns to Entries and clears filters. Scheduled notes open without needing another edit to refresh the feed.

The partner requirement is enforced by the server. Settings, data exports, and authorized attachment downloads remain available while shared features are locked. Membership and attachment visibility are rechecked before a private file is returned.

- 10 mobile tests, mobile TypeScript checks, and an iOS JavaScript export.
- Browser checks with two local accounts for invitations, failed-code recovery, journal saving, game turns, hidden choices, partner departure, and attachment downloads.

## iPhone status

The Expo / React Native companion remains in development. It includes core journal, pairing, Four-in-a-row, questions, plans, and settings flows. It has not been released on the App Store or TestFlight and does not yet have every web feature. Native Google return and photo conversion still need real-device verification.

This release provides source code, not an installable `.ipa`.

## Running this version

Use Node.js 26, run `npm ci`, then `npm run dev` for local development. Create two accounts in separate browser sessions to try the shared features. Production requires PostgreSQL, private object storage, a persistent authentication secret, and configured service credentials; see [configuration](../configuration.md).

Synchronization uses active polling. Offline writes and end-to-end encryption are not implemented. Spotify availability and playback remain subject to Spotify’s restrictions.
